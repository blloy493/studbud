How StepSpark helps

  • One step at a time. You see only the step you're on, so you always know what to do next.
  • A note on how to approach each step. StepSpark explains what each question is asking. It never provides the answer.
  • Help when you're stuck. The on-screen avatar gives hints that get more detailed if you still need them.
  • No switching tabs. The steps and the avatar sit on the page you're already working on.
  • Optional focus timer. A 25-minute timer for each step, and an avatar that levels up as you finish steps.

StepSpark can miss parts of complicated PDFs, such as tables, graphs and long structured prompts. Skim the steps against your assignment sheet before you start.

What is a Chrome extension?

A Chrome extension is a small add-on for the Chrome web browser, the way an app adds features to a phone. It isn't a separate program. You install it from the Chrome Web Store in a few clicks, and it adds a feature to the browser. StepSpark adds a step-by-step helper next to the page your student is already working on.

  • It's easy to remove. Right-click the StepSpark icon in the Chrome toolbar and choose "Remove from Chrome."
  • It only works in Chrome on a computer. It does nothing on phones and tablets.
  • School-managed computers may block it. Some schools stop students from adding extensions. If the install button is missing or greyed out, that is the likely reason. Your student can use a personal computer instead.

How to install StepSpark

Install video coming soon
  1. Use Chrome on a computer. Windows, Mac, Linux and Chromebook work. Phones and tablets can't install Chrome extensions.
  2. Add it from the Chrome Web Store. Open the StepSpark page, click "Add to Chrome", then "Add extension" in the pop-up.
  3. Pin StepSpark (optional). Click the puzzle-piece icon in the Chrome toolbar, then the pin next to StepSpark. This keeps its settings one click away.
  4. Open your assignment. Open or refresh the page you're working on. The avatar appears at the bottom left and the step widget at the bottom right. Chrome blocks extensions on the Chrome Web Store and chrome:// pages, so StepSpark won't show there.
  5. Add your assignment. Name your avatar, then upload a PDF, PNG or JPEG (up to 3 MB) or paste the text. Answer any quick questions, then follow the steps.

About Chrome's permission pop-up. Chrome will say StepSpark can "read and change all your data on all websites". StepSpark needs this only to show the avatar and step widget on whatever page you're studying on. It does not read page content, form fields or your browsing history. You can turn StepSpark off on any site from its toolbar popup. Details are in the privacy policy.
